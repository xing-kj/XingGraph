## 关于我 / About

我是一个开发者，关注 **AI 记忆与检索系统**、**知识图谱**、**Agent 基础设施**。
当前主项目是 [XingGraph](https://github.com/xing-kj/XingGraph) —— 知识图谱驱动的 RAG 与多主体对比问答引擎。

## 主要项目 / Pinned projects

| 项目 | 角色 | 简介 |
|---|---|---|
| [XingGraph](https://github.com/xing-kj/XingGraph) | 主项目 | 知识图谱 + RAG 引擎，WIKI 多主体渐进式检索，Apache-2.0 |
| [xinggraph-mcp](https://github.com/xing-kj/xinggraph-mcp) | MCP 服务 | 把 XingGraph 作为 Model Context Protocol 工具暴露给 agent |
| [xinggraph-frontend](https://github.com/xing-kj/xinggraph-frontend) | 可视化 | 六层节点图谱的前端（搜索 / Story / Flow / Force 布局） |
| [xinggraph-starter-kit](https://github.com/xing-kj/xinggraph-starter-kit) | 入门模板 | 一键启动 XingGraph 的最小工程示例 |

## 技术栈 / Stack

`Python 3.10+` · `Neo4j` · `FastAPI` · `MCP` · `RDF/OWL` · `Qdrant` · `SQLite` · `TypeScript` · `React`

## 关注领域 / Focus

- **结构化检索**：实体锚定 + 图遍历 + Wiki 扩展（不要裸向量、也不要全局社区摘要）
- **可观测**：检索 trace 端到端可读，每一步都能被调试
- **可溯源**：回答绑定原文 chunk，引用到具体章节标题
- **少幻觉**：subject 文档白名单硬过滤，他文不入上下文
