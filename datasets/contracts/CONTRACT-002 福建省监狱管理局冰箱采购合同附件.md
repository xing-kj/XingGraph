# 福建省监狱管理局政府采购冰箱技术附件
## 1. 合同基础信息
| 信息项 | 具体内容 |
| :--- | :--- |
| 合同编号 | 无 |
| 采购方 | 福建省监狱管理局 |
| 供应商 | 政府采购平台中标供应商 |
| 货物名称 | 家用电冰箱 |
| 采购数量 | 一批，具体数量以采购订单为准 |

## 2. 技术参数要求
| 技术项 | 约定参数 | 允许偏差范围 |
| :--- | :--- | :--- |
| 总容积 | 601-700L | 实测容积不低于约定值的98% |
| 能效等级 | 3级或更优 | 不接受低于约定等级的产品 |
| 制冷方式 | 直冷 | 无 |
| 控温方式 | 电脑控温 | 无 |
| 门体类型 | 对开门 | 无 |
| 面板材质 | 冷轧钢 | 无 |
| 机身颜色 | 白色 | 无 |
| 显示屏 | 无LED显示屏 | 无 |
| 除霜模式 | 手动除霜 | 无 |
| 压缩机类型 | 定频 | 无 |
| 制冷剂型号 | R600a | 无 |
| 其他要求 | 产品需提供中国国家强制性产品认证证书（3C认证） | 无 |

## 3. 履约验收要求
| 验收维度 | 具体验收标准 |
| :--- | :--- |
| 验收时间 | 供应商提出验收申请之日起15日内组织验收 |
| 验收组织 | 由采购方牵头组织，需邀请第三方专业检测机构参加验收 |
| 检测项目 | 产品实际容积、能效等级、制冷性能、噪声值、安全指标 |
| 验收标准 | 所有实测参数不低于合同约定要求，第三方检测机构出具合格报告 |
| 验收资料 | 供应商需提供产品合格证、官方检测报告、能效标识认证报告、3C认证证书、安装使用说明书等完整资料 |
| 不合格处理 | 验收不合格的，供应商需在采购方指定时限内更换合格产品，重新组织验收 |

## 4. 售后服务约定
| 服务项 | 具体服务内容 |
| :--- | :--- |
| 质保期限 | 整机质保不少于1年，自验收合格之日起计算 |
| 响应时间 | 质保期内，供应商需在接到采购方报修通知后24小时内上门维修 |
| 维修要求 | 维修过程中更换的配件需为原厂全新配件，维修完成后需对维修部位提供不少于3个月的保修服务 |
| 退换货约定 | 同一产品出现2次及以上同一质量问题且无法修复的，供应商需免费更换同型号合格产品 |

## 5. 其他约定
本合同项下货物的技术标准，除合同另有约定外，均按照国家相关行业标准执行；合同未明确约定的技术参数，需不低于国家相关行业标准的最低要求。
