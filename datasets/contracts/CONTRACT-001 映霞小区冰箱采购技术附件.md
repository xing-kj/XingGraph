# 长沙经开区租赁住房建设项目(映霞小区)家电采购及安装项目（第一批）采购需求
## 1. 项目基础信息
| 信息项 | 具体内容 |
| :--- | :--- |
| 项目名称 | 长沙经开区租赁住房建设项目(映霞小区)家电采购及安装项目（第一批） |
| 合同编号 | 无 |
| 采购方 | 长沙经济技术开发区城建开发有限公司 |
| 供应商 | 公开招标确定 |
| 货物名称 | 家用电冰箱 |
| 采购数量 | 第一批采购若干台，最终按实际到货验收数量结算 |

## 2. 技术参数要求
本项目采购的冰箱，技术参数需满足以下最低要求：
| 技术项 | 约定参数要求 |
| :--- | :--- |
| 总容积 | 不低于220升，至少包含冷藏室、冷冻室、变温室三个独立舱室 |
| 制冷方式 | 风冷（无霜），不接受直冷式冷藏冷冻箱 |
| 能效等级 | 三级或更优（二级/一级均可），能效标识需符合国家相关标准 |
| 温控方式 | 电脑温控，支持人工智慧自动调温功能 |
| 压缩机类型 | 变频，提供不少于6年的官方质保服务 |
| 噪声值 | 运行噪声不高于40dB(A) |
| 冷藏室容积 | 至少占总容积的65% |
| 冷冻室容积 | 不低于30升 |
| 变温室容积 | 不低于20升 |
| 其他要求 | 冰箱面板需采用金属材质，颜色为白色或灰色，表面采用抗划伤、防指纹处理；所有参数需符合国家强制标准要求 |

## 3. 商务条款对应要求
| 商务项 | 约定内容 |
| :--- | :--- |
| 供货时限 | 自合同签订之日起7天内完成供货及安装调试 |
| 安装要求 | 免费送货上门并安装调试，安装过程中产生的辅料费用由供应商承担 |
| 验收标准 | 除满足国家强制标准及合同约定的技术参数要求外，还需提供产品合格证、官方检测报告等资料 |
| 质保期限 | 整机质保不少于1年，主要部件（压缩机、温控器、蒸发器、冷凝器）质保不少于3年 |
| 付款条件 | 货到验收合格后，供应商提供全额发票及验收合格凭证，采购方支付100%合同款 |

## 4. 验收标准
冰箱到货后，供需双方将按以下标准组织验收：
1. 包装完好无损，外观无明显划痕、凹陷，面板颜色与合同约定一致；
2. 产品合格证、使用说明书、保修卡、能效标识等随机资料齐全；
3. 实测技术参数满足合同约定的最低要求；
4. 制冷系统运行正常，各模式调温功能流畅，箱内温度下降速度符合标准；
5. 噪声实测值不高于40dB(A)；
6. 所有检验项目符合国家强制标准及合同约定要求。
